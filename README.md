# Phone Tablet — الهاتف كجرافيك تابلت للابتوب

شاشة اللابتوب تظهر على الهاتف، وترسم عليها بإصبعك أو بقلم الهاتف. الخادم يحوّل لمسك إلى **قلم حقيقي في ويندوز** (Windows Ink) مع الضغط.

```
 اللابتوب (ويندوز)                          الهاتف (أندرويد)
 ┌──────────────────┐   صورة الشاشة (JPEG)   ┌──────────────────┐
 │ PhoneTabletServer│ ─────────────────────▶ │  Phone Tablet app│
 │  (نافذة + Python)│ ◀───────────────────── │  (Kotlin)        │
 └──────────────────┘   لمس + قلم + اختصارات └──────────────────┘
          اتصال واحد TCP عبر Wi-Fi أو USB
```

## الميزات

| الميزة | الوصف |
|---|---|
| **تكبير وتحريك** | بإصبعين: تكبير (pinch) وتحريك. الخادم يقص الجزء المكبّر من الشاشة الأصلية فتبقى الصورة حادة |
| **مؤشر الماوس** | يظهر كحلقة على الصورة |
| **أزرار اختصار** | Undo / Redo / Eraser / Brush / Size ± / Save (من القائمة الجانبية) |
| **زر القلم الجانبي** | يعمل كزر أيمن، والطرف الآخر للقلم كممحاة (للأجهزة التي تدعمه) |
| **إعادة اتصال تلقائي** | لو انقطع الاتصال يعيد التطبيق المحاولة كل ثانيتين |
| **PIN** | رقم من 6 خانات يظهر في نافذة ويندوز ويدخله الهاتف |
| **نافذة ويندوز** | حالة الاتصال والـ PIN والإعدادات والسجل |
| **اكتشاف تلقائي** | زر Scan في التطبيق يجد الابتوب على الشبكة |
| **اختيار الشاشة والمنطقة** | زر Screen لتبديل الشاشات، وزر Window لعرض النافذة النشطة بملء الهاتف، وزر Fit للرجوع للشاشة كاملة |

## المحتويات

| المجلد | الوظيفة |
|---|---|
| `server/` | خادم ويندوز (Python): بث الشاشة وحقن القلم، ونافذة tkinter |
| `android/` | تطبيق أندرويد (Kotlin) |
| `.github/workflows/build.yml` | اختبار الخادم وبناء `PhoneTablet.apk` و`PhoneTabletServer.exe` تلقائيًا |

## التحميل الجاهز

من تبويب **Releases** (أو **Actions** ثم آخر تشغيل ناجح ثم **Artifacts**):
- `PhoneTablet.apk` ← ثبّته على الهاتف.
- `PhoneTabletServer.exe` ← شغّله على الابتوب.

## الاستخدام

1. **الابتوب:** شغّل `PhoneTabletServer.exe` (اسمح له في جدار الحماية للشبكات **الخاصة**). ستظهر نافذة فيها عنوان IP وPIN.
2. **الهاتف:** افتح التطبيق على نفس شبكة الواي فاي، واضغط **Scan** واختر ابتوبك، واكتب الـ PIN، ثم **Connect**.
3. **عبر USB (أقل تأخيرًا):** فعّل USB debugging، ونفّذ على الابتوب `adb reverse tcp:5555 tcp:5555`، ثم في التطبيق اكتب `127.0.0.1` والـ PIN واضغط Connect.
4. افتح برنامج رسم يدعم Windows Ink (Krita، Photoshop، Paint...). في Krita: Settings ← Configure Krita ← Tablet Settings ← **Windows Ink**.

### التحكم على الهاتف

- **قلم الهاتف:** يرسم، وزره الجانبي = كليك يمين، وطرفه الخلفي = ممحاة.
- **إصبع واحد:** يرسم (أو يحرّك العرض إن اخترت `Finger: Pan`).
- **إصبعان:** تكبير وتحريك دائمًا.
- **Menu / Hide:** إظهار أو إخفاء القائمة الجانبية.
- **Redo** ضغطة طويلة = Ctrl+Shift+Z (الاختصار المستخدم في Krita وPhotoshop)، والضغطة العادية = Ctrl+Y.

> الاختصارات تعمل على البرنامج الذي عليه التركيز في الابتوب. اختصارات البرامج تختلف، فإن لم يطابق اختصار برنامجك (مثل `E` للممحاة) فلن يؤثر.

## سطر الأوامر (اختياري)

```
python tablet_server.py            # النافذة
python tablet_server.py --cli      # بدون نافذة
python tablet_server.py --dry-run  # اختبار على أي نظام (نمط ملوّن بدل الشاشة)
```
خيارات: `--port` `--monitor` `--fps` `--quality` `--mouse` `--pin 123456` `--no-pin`

## البناء من المصدر

**الخادم (exe):**
```
pip install -r server/requirements.txt pyinstaller
pyinstaller --onefile --windowed --name PhoneTabletServer server/tablet_server.py
```
**التطبيق:** افتح مجلد `android/` في Android Studio، أو `gradle -p android assembleDebug` (Gradle 8.9 وJDK 17 وAndroid SDK).

**الاختبار:** `python server/test_protocol.py` (يختبر البروتوكول كاملًا بدون ويندوز).

## ملاحظات وحدود

- الاتصال **غير مشفّر**: الـ PIN يمنع الاتصال العرضي من أجهزة الشبكة، لكنه ليس حماية قوية. استخدمه على شبكاتك الموثوقة فقط.
- زر Window يعرض النافذة النشطة وقت الضغط (التي عليها التركيز في الابتوب).
- الإصبع يرسل ضغطًا ثابتًا، والضغط الحقيقي يحتاج قلم ستايلس يدعمه هاتفك.
- تم اختبار الخادم والبروتوكول آليًا، أما حقن القلم وتطبيق أندرويد فيُختبران على جهازك.

## البروتوكول

اتصال TCP واحد على المنفذ 5555، واكتشاف UDP على المنفذ 5556. التفاصيل الكاملة في أول ملف `server/common.py`.

## أفكار قادمة

- ترميز H.264 بدل JPEG لتأخير أقل.
- تشغيل تلقائي مع ويندوز ومثبّت (installer).
- منع لمس راحة اليد (palm rejection) وضبط حساسية الضغط.
