# Phone Tablet — الهاتف كجرافيك تابلت للابتوب

شاشة اللابتوب تظهر على الهاتف، وترسم عليها بإصبعك أو بقلم الهاتف. الخادم يحوّل لمسك إلى **قلم حقيقي في ويندوز** (Windows Ink) مع الضغط.

```
 اللابتوب (ويندوز)                         الهاتف (أندرويد)
 ┌──────────────────┐   صورة الشاشة (JPEG)   ┌──────────────────┐
 │ PhoneTabletServer│ ─────────────────────▶ │  Phone Tablet app│
 │  (Python / exe)  │ ◀───────────────────── │  (Kotlin)        │
 └──────────────────┘   لمس + ضغط القلم      └──────────────────┘
          اتصال واحد TCP عبر Wi-Fi أو USB
```

## المحتويات

| المجلد | الوظيفة |
|---|---|
| `server/` | خادم ويندوز (Python): يلتقط الشاشة ويبثها، ويحقن القلم |
| `android/` | تطبيق أندرويد (Kotlin) |
| `.github/workflows/build.yml` | بناء `PhoneTablet.apk` و`PhoneTabletServer.exe` تلقائيًا |

## التحميل الجاهز (بدون بناء)

من تبويب **Actions** في GitHub افتح آخر تشغيل ناجح ونزّل:
- `PhoneTablet-apk` ← ملف `PhoneTablet.apk` ثبّته على الهاتف (فعّل "التثبيت من مصادر غير معروفة").
- `PhoneTabletServer-exe` ← ملف `PhoneTabletServer.exe` شغّله على الابتوب.

وعند إنشاء وسم إصدار مثل `v1.0` يُنشر الملفان في صفحة **Releases** تلقائيًا.

## التشغيل

### 1) على الابتوب

بالـ exe: شغّل `PhoneTabletServer.exe` (اسمح له في جدار الحماية للشبكات **الخاصة**).

أو من الكود:

```
cd server
pip install -r requirements.txt
python tablet_server.py
```

سيطبع عنوان IP الخاص بالابتوب. خيارات مفيدة:

| الخيار | المعنى |
|---|---|
| `--monitor 2` | بث شاشة أخرى (الافتراضي 1 = الرئيسية) |
| `--fps 30` | أقصى عدد إطارات في الثانية |
| `--quality 70` | جودة JPEG (أقل = أسرع) |
| `--mouse` | وضع الماوس العادي (بدون ضغط) |
| `--dry-run` | نمط اختبار بدل الشاشة، للتجربة على أي نظام |

### 2) على الهاتف

**عبر Wi-Fi:** الهاتف والابتوب على نفس الشبكة. اكتب IP الابتوب والمنفذ `5555` ثم Connect.

**عبر USB (أقل تأخيرًا وأوضح صورة):**
1. فعّل **USB debugging** في خيارات المطوّر.
2. نفّذ على الابتوب مرة واحدة بعد توصيل الكابل:
   ```
   adb reverse tcp:5555 tcp:5555
   ```
3. في التطبيق اكتب `127.0.0.1` والمنفذ `5555` ثم Connect.

### 3) الرسم

- افتح برنامج رسم يدعم Windows Ink (Krita، Photoshop، Paint، OneNote...).
- في Krita: Settings ← Configure Krita ← Tablet Settings ← **Windows Ink**.
- زر الرجوع في الهاتف يقطع الاتصال.
- الإصبع يرسل ضغطًا ثابتًا، والضغط الحقيقي يحتاج قلم ستايلس يدعمه هاتفك.

## البناء من المصدر

**الخادم (exe):**
```
pip install -r server/requirements.txt pyinstaller
pyinstaller --onefile --name PhoneTabletServer server/tablet_server.py
```

**التطبيق:** افتح مجلد `android/` في Android Studio واضغط Run، أو من سطر الأوامر مع Gradle 8.9 وJDK 17 وAndroid SDK:
```
gradle -p android assembleDebug
```
الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`

## ملاحظات وحدود حاليًا

- المؤشر لا يظهر في الصورة المبثوثة، لكن ما ترسمه يظهر.
- البث MJPEG بسيط: جودة وتأخير مقبولان، ويتحسنان كثيرًا عبر USB.
- الكتابة فوق نافذة بصلاحيات مدير (Run as administrator) قد تتجاهل القلم ما لم يُشغَّل الخادم كمدير أيضًا.
- لم يُختبر حقن القلم وتطبيق أندرويد على أجهزة حقيقية بعد.

## البروتوكول

اتصال TCP واحد على المنفذ 5555.

**هاتف ← خادم:** حزمة 13 بايت big-endian: `type(1) + x(float) + y(float) + pressure(float)`.
الأنواع: 0 ضغط، 1 حركة، 2 رفع، 3 تحويم، 4 مغادرة التحويم، 10 تغيير الحجم (x=عرض شاشة الهاتف، y=الارتفاع بالبكسل).
الإحداثيات من 0 إلى 1 نسبة إلى صورة الشاشة المعروضة.

**خادم ← هاتف:** إطارات، كل إطار `[طول 4 بايت][بيانات JPEG]`.

## أفكار للتطوير

- تكبير وتحريك (zoom/pan) داخل التطبيق.
- أزرار اختصار (تراجع، ممحاة) وزر القلم الجانبي.
- رسم المؤشر في الصورة.
- ترميز H.264 بدل JPEG لتأخير أقل.
- اكتشاف الخادم تلقائيًا على الشبكة.
